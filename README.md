Ever felt that playing survival minecraft has become boring?
Want to spice it up?

This Mod transforms Minecraft from a relaxing sandbox into a high-stakes game of Russian Roulette. Whether you are so close to those diamond ores with only half a heart left or finally almost finishing your dream base, there's always a chance to blow up everything and go back to square one.

## Configuration

Don't like the odds? You can customize everything via the **Mod Menu**.

* **Placement Explosion Chance:** Adjust the probability of explosions when building (0-100%).
* **Break Explosion Chance:** Adjust the probability of explosions when mining (0-100%).
* **TNT Fuse Time:** Change how fast the TNT blows up. The time is set in Minecraft ticks (10 ticks = 1 second).

## Installation
1. Make sure you have already downloaded and setup Fabric Loader.
2. Download the latest release from the [releases tab](https://github.com/codecooker1/Mod/releases).
3. Drop the '.jar' file in your mods folder
4. Enjoy!
